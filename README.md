# Campus Knowledge AI Assistant

An AI-powered knowledge assistant that helps students find information from college documents using Retrieval-Augmented Generation (RAG).

## Problem

Students often struggle to find important academic information hidden across PDFs such as regulations, syllabi, notices, internship guidelines, and placement policies.

## Solution

Campus Knowledge AI Assistant allows users to upload PDF documents and ask natural language questions. The system retrieves relevant document sections using embeddings and vector search before generating grounded answers using an LLM.

## Features

- PDF document upload
- Text extraction and chunking
- Embedding generation
- Vector search
- Retrieval-Augmented Generation (RAG)
- Natural language Q&A
- Streamlit web interface

## Tech Stack

- Python
- Streamlit
- Google Gemini
- FAISS
- LangChain
- Sentence Transformers
